#  CriptoEx

Agente de IA especializado en criptomonedas y blockchain, construido con **FastAPI**, **Agno** y **DeepSeek** (vía OrcaRouter).

##  Características

- 🤖 **Agente IA** con DeepSeek v4 Flash (vía OrcaRouter)
- 🔍 **Búsqueda web** en tiempo real con DuckDuckGo
- ️ **Scraping** de páginas web con WebsiteTools
- 📚 **Base de conocimientos** local con ChromaDB
-  **Autenticación JWT** con tokens de 60 minutos
- 💬 **API de Agentes** para interactuar con el agente
- 📋 **API de Sessions** para gestionar historial de conversaciones
- ⚡ **WebSocket** para eventos en tiempo real
- 🎨 **UI propia** con login y dashboard

## ️ Requisitos

- Python 3.12+
- Conda o venv para entornos virtuales
- Cuenta en [OrcaRouter](https://orcarouter.ai) con API key
